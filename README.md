# Netflix Landing Page Clone

A static, front-end clone of the Netflix India landing page, built with plain HTML and CSS. This project is for learning and practice purposes only and is not affiliated with Netflix.

## Preview

The page includes:

- **Navigation bar** with the Netflix logo, a language button and a Sign In button
- **Hero section** with the tagline, pricing text and an email sign-up input with a "Get Started" button
- **Feature sections** (alternating image/text layout):
  - Enjoy on your TV
  - Download your shows to watch offline
  - Watch everywhere
  - Create profiles for kids
- **FAQ section** with common questions
- **Footer** with helpline text and link columns

## Tech Stack

- HTML5
- CSS3 (`style.css`)

## Project Structure

```
.
├── index.html    # Page markup
├── style.css     # Styling for the page

```

## Getting Started

1. **Clone or download** this repository:
```bash
   git clone <your-repo-url>
   cd <your-project-folder>
```
2. **Open the page** in your browser:
   - Double-click `index.html`, or
   - Use the *Live Server* extension in VS Code for auto-reload.

No build tools or dependencies are required. An internet connection is needed to load the logo and images, which are hosted externally.

## Features

- Clean, semantic page structure
- Reusable section layout using the shared `first` class
- Responsive-friendly layout (can be improved further with media queries)
- Image assets loaded from external CDNs
